# Sign-Language-Interpreter
The aim of this project is to design and implement a demo of the real-time British Sign 
Language Interpreter, that can be used by the hearing impaired community, which 
implements a robust Python to LeapC interface which shows in real-time frames, hands and 
fingers and a Convolutional Neural Network that can recognise at least 10 distinct British 
sign language hand signs. It will also include a user-friendly Python Graphical user interface, 
improving the usability accessibility of the system. The Sign Language Interpreter System 
would be most beneficial to the hearing impaired who are reliant on communication assisting 
tools in their everyday life and make up, as of February 2025, over 5% of the world’s 
population (approximately 430 million people) and it is also estimated that by 2050 every 1 
in 10 people will have disabling hearing loss [1]. The system will help maintain a strong 
connection between people whether they are deaf or not, the world will be connected by 
maintaining communication.
